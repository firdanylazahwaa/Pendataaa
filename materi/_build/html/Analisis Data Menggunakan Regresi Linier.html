Analisis Data Menggunakan Regresi Linier#

Proyek ini bertujuan untuk menganalisis hubungan antara variabel x dan y menggunakan metode Regresi Linier. Analisis dilakukan dengan dua cara, yaitu:

  • Menggunakan GeoGebra untuk visualisasi grafik regresi.

  • Menggunakan Python untuk menghitung koefisien regresi secara manual dan menggunakan library sklearn.

4. Menghitung Gradien (a)#

Rumus gradien:

\[ a=\frac{n\sum xy-(\sum x)(\sum y)}{n\sum x^2-(\sum x)^2} \]

Substitusi nilai:

\[ a=\frac{7(112)-(26)(28)}{7(104)-(26)^2} \]
\[ a=\frac{784-728}{728-676} \]
\[ a=\frac{56}{52} \]
\[ a=1.0769 \]

5. Menghitung Intercept (b)#

Rumus intercept:

\[ b=\frac{\sum y-a\sum x}{n} \]

Substitusi nilai:

\[ b=\frac{28-(1.0769)(26)}{7} \]
\[ b \approx 0 \]

6. Persamaan Regresi#

Persamaan regresi yang diperoleh:

\[ y = 1.0769x \]
import numpy as np
from sklearn.linear_model import LinearRegression

# Data
x = np.array([2,4,5,3,3,4,5]).reshape(-1,1)
y = np.array([2,3,5,4,3,5,6])

# Membuat model regresi
model = LinearRegression()

# Training model
model.fit(x, y)

# Mengambil koefisien regresi
a = model.coef_[0]
b = model.intercept_

# Output
print("Nilai gradien (a) =", a)
print("Nilai intercept (b) =", b)

print(f"Persamaan regresi: y = {a:.4f}x + {b:.4f}")
